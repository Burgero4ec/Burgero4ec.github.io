# CLAUDE.md — Руководство проекта Global Lens для Claude Code

## Описание проекта
**Global Lens** — интерактивный веб-портал проекта с геополитической картой, 3D-глобусом, базой знаний (Wiki), статистикой игроков, правилами сервера и личным кабинетом.
- Сайт: https://burgero4ec.github.io/
- Архитектура: Модульный Vanilla JavaScript (ES Modules), HTML5, CSS3.
- Ключевые библиотеки:
  - Three.js (`0.161.0`) — 3D визуализация.
  - Globe.gl — интерактивный 3D-глобус с геополитическими границами (`world_geo.js`).
  - Matter.js (`0.19.0`) — 2D-физика в блоке донатов.
  - Google Fonts: JetBrains Mono, Nunito.

---

## Архитектура и структура файлов
- `index.html` — Главная страница и единый каркас (SPA-подобная навигация).
- `style.css` — Основные стили, темы оформления, адаптивная верстка под мобильные устройства.
- `app.js` — Корневая точка входа (`import './js/app.js'`).
- `js/`:
  - `app.js` — Главный координатор и регистратор методов в глобальный `window` (для сохранения работы inline-обработчиков `onclick` в HTML).
  - `navigation.js` — Маршрутизация секций (`go(section)`), управление мобильным меню (drawer).
  - `globe.js` — Настройка и рендеринг 3D-глобуса, подсветка государств и альянсов.
  - `season.js` — Обработка данных текущего сезона, модальные окна стран.
  - `auth.js` — Авторизация через Discord, профиль игрока, вебхуки.
  - `donate.js` — Физика монет/кубиков Matter.js, Discord Lanyard.
  - `wiki.js` & `wiki-data.js` — Система вики-статей и документации.
  - `alliances.js` — Управление союзами и отображение на глобусе.
  - `staff.js` & `staff_data.js` — Карточки команды и модальные окна.
  - `shame.js`, `archives.js`, `news_press.js`, `stats.js` — Вспомогательные разделы.
- `*.json` (корень): `players.json`, `countries2020.json`, `countries2014.json`, `autonomy.json`, `pmc.json`.

## Запуск и локальная разработка
> ⚠️ **ВАЖНО**: Проект использует ES Modules (`type="module"`, `importmap`) и локальные `fetch` JSON-файлов. Открытие через `file:///` работать не будет из-за CORS. Обязателен локальный HTTP-сервер.

### Команды запуска локального сервера:
- **Python (рекомендуется)**:
  ```powershell
  python -m http.server 8000
  ```
- **Node.js (npx serve)**:
  ```powershell
  npx serve . -l 8000
  ```
Сайт будет доступен по адресу: `http://localhost:8000`

## Правила работы с кодом для Claude
1. **Обратная совместимость с HTML-атрибутами**: Все методы, вызываемые из `index.html` через `onclick="methodName(...)"`, ДОЛЖНЫ быть экспортированы в `window` внутри `js/app.js` (например, `window.go = go;`).
2. **Язык интерфейса и комментариев**: Русский язык.
3. **Цветовая палитра**: Основной акцентный цвет темы — зеленый `#4ade80`, темный фон `#0d1711` / `#060a08`.
4. **Безопасность**: Никогда не вшивать в код секретные ключи или токены Discord бота/вебхуков.

## Чек-лист проверки сайта (Testing & QA)
При аудите и проверке сайта в первую очередь проверять:
1. **Консоль браузера (DevTools)**: Отсутствие ошибок загрузки модулей (MIME types, 404 по JSON-файлам, WebGL context errors).
2. **Работу 3D-глобуса**: Корректный рендеринг canvas, реакция на зум и вращение, отсутствие утечек памяти Three.js.
3. **Мобильное меню и адаптивность**: Проверить на экранах 375px (iPhone) и 768px (iPad) — оверлеи, кнопки закрытия модалок.
4. **Работу переключателей**: Темная/зеленая тема, вкладки Wiki, фильтры стран.
